# adventist-inv-app

Страница-приглашение на онлайн субботнее служение (Google Meet) — Yeddinci Günün Adventistləri Dini İcması, Bakı.

- `index.html`, `assets/` — сама страница (статический HTML5, без сборки)
- `assets/img/og/` — превью-картинки 1200×630 для WhatsApp/Telegram
- `tools/make_previews.py` — пересоздаёт превью и фото из `images/preview/` (`pip install pillow`, запуск из корня проекта)
